# 太极拳动作识别与评分系统

## 项目概述

太极拳动作识别与评分系统是一个基于计算机视觉的应用程序，旨在帮助太极拳学习者改进动作。系统能够：

- 从视频中识别人体关键点
- 比较学生动作与标准动作
- 提供量化评分和改进建议
- 可视化动作对比

本系统采用低成本、低技术难度的方案设计，适合没有计算机基础的用户使用。

## 技术栈

- **MediaPipe**: Google开发的开源计算机视觉库，用于姿态估计
- **FastDTW**: 动态时间规整算法的快速实现，用于比较时间序列
- **Streamlit**: 用于构建简单直观的用户界面
- **OpenCV**: 用于视频处理
- **NumPy/SciPy**: 用于数据处理和分析

## 安装指南

### 系统要求

- Windows 7/10/11
- Python 3.8或更高版本
- 摄像头（用于实时录制功能）

### 快速安装

1. 确保已安装Python 3.8或更高版本
2. 双击`run.bat`文件，它会自动安装所有必要的库并启动应用程序

### 手动安装

如果自动安装失败，请按照以下步骤手动安装：

1. 打开命令提示符（按Win+R，输入cmd，按回车）
2. 安装必要的库：

```
pip install mediapipe opencv-python numpy matplotlib fastdtw scipy streamlit
```

3. 启动应用程序：

```
cd 路径\到\taijiquan文件夹
streamlit run app.py
```

## 使用指南

### 文件夹结构

- `data/`: 存储视频和处理后的数据
  - `standard/`: 标准动作视频
  - `student/`: 学生动作视频
  - `processed/`: 处理后的关键点数据
- `results/`: 评分结果和可视化

### 使用步骤

1. **准备标准动作**：
   - 将标准动作视频放入`data/standard`文件夹，或
   - 通过应用界面上传标准动作视频，或
   - 使用应用界面实时录制标准动作

2. **评估学生动作**：
   - 上传学生动作视频，或
   - 使用应用界面实时录制学生动作

3. **查看评分结果**：
   - 系统会自动计算评分（0-100分）
   - 显示动作错误分析
   - 提供针对性的改进建议
   - 展示动作比较可视化

### 录制建议

为获得最佳效果，请遵循以下建议：

- 确保光线充足，背景简单
- 穿着与背景对比明显的衣服
- 确保全身在摄像头视野内
- 动作速度应与标准动作相近
- 录制时保持稳定，避免快速移动

## 数据处理流程

1. **关键点提取**：使用MediaPipe从视频中提取33个人体关键点
2. **数据标准化**：以髋部为参考点，根据身体比例进行缩放
3. **特征提取**：计算关节位置和关节角度
4. **动作比较**：使用FastDTW算法比较学生动作和标准动作
5. **评分计算**：基于DTW距离计算评分（0-100分）
6. **错误分析**：识别误差最大的关节或角度，提供改进建议

## 高级自定义

### 调整评分权重

您可以在`scoring.py`文件中修改特征权重：

```python
# 默认权重：位置特征权重0.7，角度特征权重0.3
feature_count = student_features.shape[1]
position_count = feature_count - 5  # 减去5个角度特征
weights = np.ones(feature_count)
weights[:position_count] *= 0.7 / position_count
weights[position_count:] *= 0.3 / 5
```

### 添加新的特征

您可以在`scoring.py`文件的`calculate_joint_angles`函数中添加新的角度计算，然后在`feature_names`列表中添加新特征的名称，并在`get_error_suggestions`函数中添加相应的改进建议。

## 常见问题

**Q: 系统无法检测到我的动作**
A: 确保光线充足，穿着与背景对比明显的衣服，并确保全身在摄像头视野内。

**Q: 评分似乎不准确**
A: 尝试重新录制标准动作，确保动作清晰完整。也可以调整`scoring.py`中的权重。

**Q: 应用程序无法启动**
A: 确保已安装Python 3.8或更高版本，并已安装所有必要的库。检查错误消息以获取更多信息。

## Autodl 云服务器一键部署（详细教程）

以下步骤适合非专业人士，逐步照做即可完成部署与运行。

- 准备：将整个项目文件夹上传到 Autodl（建议路径 `~/taijiquandongzuoshibie`）。
- 进入终端：在 Autodl 控制台中进入对应实例，打开“终端/Terminal”。

### 1）进入项目目录
- 终端输入：
  - `cd ~/taijiquandongzuoshibie`

### 2）一键安装依赖
- 运行：
  - `bash setup_autodl.sh`
- 该命令会自动：
  - 安装系统依赖：`ffmpeg`、`libgl1`、`libglib2.0-0`、`wkhtmltopdf`（用于PDF导出，可选）。
  - 创建并启用 Python 环境（优先使用 `conda`，否则使用 `venv`）。
  - 按 `requirements.txt` 安装所需 Python 库。
  - 写入默认 Streamlit 配置（端口 6006）。

### 3）启动服务
- 运行：
  - `bash start_autodl.sh`
- 启动后终端会显示访问链接（本机地址）。

### 4）在 Autodl 面板开通外网访问（无需备案）
- 在该实例的“服务/Service”或“端口映射/Port”页面：
  - 新增一个 HTTP 服务，端口填 `6006`。
  - 系统会生成一个公网访问地址（形如 `http://<域名或IP>:6006/`）。
  - 用手机或电脑浏览器打开该地址即可访问系统。

### 5）首次准备标准动作
- 将标准动作视频放入 `./standard_videos/`（若无可新建）。
- 在网页中选择“处理标准动作视频”，系统会生成关键点文件至 `./processed_standard_points/`。

### 6）受试者使用流程（手机端）
- 打开上一步的公网地址；
- 在页面选择一个标准动作；
- 上传自己的动作视频（或使用页面录制功能）；
- 点击评分，系统会显示得分与改进建议；
- 评分结果与关键点文件保存在项目根目录下对应文件夹。

### 7）常见问题与排障
- `ImportError: libGL.so.1`：运行 `bash setup_autodl.sh` 已自动安装 `libgl1`；若仍报错，重启终端再试。
- `mediapipe` 安装失败：多为网络问题，脚本已使用清华镜像；可重复执行或改用 `pip install -r requirements.txt`。
- 上传视频过大：建议控制在 1GB 以内；如需更大文件，将 `~/.streamlit/config.toml` 中 `server.maxUploadSize` 提高（默认 Streamlit 允许较大上传）。
- 页面无响应：重启服务（按 `Ctrl+C` 停止后重新 `bash start_autodl.sh`）。
- 识别精度不稳定：确保标准动作与学生动作画面清楚、光线充足、画面包含全身。

### 8）上线/下线与数据
- 上线：`bash start_autodl.sh`（保持终端打开即可）。
- 下线：在启动终端按 `Ctrl+C` 停止；或关闭实例服务映射。
- 数据位置：
  - 标准动作关键点：`./processed_standard_points/`
  - 学生评分结果与关键点：系统运行过程中在项目根目录生成相应文件夹与结果文件。
